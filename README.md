# Naman Kachroo · personal site

A single-page pixel-art story site for Naman Kachroo, founder of Thryve.

- `index.html` holds all markup, styles and scripts.
- `assets/` holds fonts (SIL Open Font License) and the pixel art.
- No build step. Netlify publishes the folder as-is (see `netlify.toml`).

The "Ask the guide" assistant only appears when the page is opened on claude.ai; on other hosts it stays hidden.
